A canvas for your coding agent.

Design a screen, map a system or sketch an idea in an editable canvas, beside Codex or Claude Code. A free, open-source plugin that keeps your work on your computer.

Install the plugin ↓View on GitHub ↗

Requires Node.js 22 or later. No subscription. No account needed for local use.

One canvas. Room to think.

From a rough idea
to something real.

Keep the layout, the system and the notes together as editable Papers that you and your agent both work on.

Start from Home.

Home opens your Personal library. Switch to a project library or see every Paper, rename one, show it in Finder or move it to Trash and restore it later.

Make the system visible.

Library symbols cover common flowchart, C4, UML-style, BPMN-style, entity-relationship, infrastructure and Kubernetes diagrams. Connectors stay attached as you move things. These are working sketches, not formal modelling tools.

Design the screen, too.

Frames, shapes, text, freehand strokes and images, with a DESIGN.md guide beside each Paper. Switch to Inspect for measurements and feedback.

You + your AI agent

Your agent. Your canvas.

Ask Codex or Claude Code to create a Paper, revise a design or draw a diagram. Through the plugin’s local tools your agent reads and saves the same Paper you edit by hand. A save based on an out-of-date version is refused rather than overwriting your work.

Your files stay yours

Save it. Open it.
Keep working.

Each Paper is a folder of editable files on your computer. Personal Papers live in your user data folder and project Papers in the project’s Paper folder, never inside the plugin cache. Updating or removing the plugin leaves them in place.

Export selected artwork as PNG or HTML, the layers as JSON, or the whole Paper as a .paper.zip. Sharing is optional: invite someone on your local network, or create a temporary Internet link that needs the optional cloudflared tool and your computer to stay on.

Save to Notion is a manual snapshot of a Paper that you choose to take, not live sync. Changes made elsewhere are reported before anything is replaced.

Why I built this

I wanted a canvas.
Not another subscription.

I wanted somewhere to sketch systems and design interfaces with an AI agent, without paying for another design tool.

Michael Shimeles (Rasmic) built the native canvas that inspired the first version. OpenPaperDesign now continues as a lightweight plugin, with the integrations and design workflow I use in my own projects.

Free & open source

Add it to your coding agent.

OpenPaperDesign is a plugin for Codex and Claude Code, not a standalone desktop app. It requires Node.js 22 or later.

Codex

codex plugin marketplace add gustavonline/openpaperdesign
codex plugin add openpaperdesign@openpaperdesign

Then quit and reopen Codex and open OpenPaperDesign in the sidebar.

Claude Code

/plugin marketplace add gustavonline/openpaperdesign
/plugin install openpaperdesign@openpaperdesign
/openpaperdesign:home

The Home command opens the dashboard in your browser.

The plugin installs from the repository’s marketplace. A packaged plugin archive is not offered yet, and the releases page lists one only once it is published. Papers saved by the earlier standalone app are preserved, but they use a different format and are not converted automatically.
