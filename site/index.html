One canvas. Room to think.

From a rough idea
to something real.

Keep the sketch, the system and the screen together. Refine the same objects as the idea takes shape.

01

Start with the messy part.

Notes in six colours, freehand drawing and hand-drawn shapes. Get the idea down before you worry about the finish.

02

Make the system visible.

Map services, data and how the parts of a system fit together. Shapes, text and arrows stay editable as your understanding changes.

03

Design the screen, too.

Frames, layouts, components, vector paths and image fills. Work on the interface beside the diagram that explains it.

You + your AI agent

Your agent. Your canvas.

Tell Codex or Claude Code what you want to make. Through local MCP, your agent can read and change the same canvas you edit by hand. Sketch a flow, explore a layout and refine it together.

The standalone app and the Codex plugin are two ways to use OpenPaperDesign. The images show the new UI/UX development build. Desktop packages are still being qualified; see the download status below.

Why I built this

I wanted a canvas.
Not another subscription.

I wanted somewhere to sketch systems and design interfaces with an AI agent, without paying for another design tool.

Michael Shimeles built the native canvas I could start from. OpenPaperDesign builds on his paper-rs work, with the integrations and design workflow I use in my own projects.
